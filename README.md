# Munshi

**An AI CA that closes a messy month of books, recovers when they don't balance, and proves every number.**

Built solo for [neatHack](https://neatlogs.com/hackathon) (Oct 10–12, 2026). Work in progress.

- Design docs: [`docs/idea/`](docs/idea/00-README.md)
- Data: real public receipts/invoices (CORD, SROIE), real peer financials (SEC EDGAR, Companies House). The demo business's bank statement is **generated** from those documents and labelled as such.
